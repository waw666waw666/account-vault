# Account Vault · 账号库

> **我攒了一堆谷歌号。邮箱我记不住，但头像我记得住。**

一个**靠头像认账号**的本地账号管理工具。

粘贴一张账号列表截图，它自动把每个账号的**头像抠出来**、识别出邮箱，整理成一眼就能认出的卡片。全部数据只存在你自己的浏览器里 —— 不联网、不上传、无后端。

## 为什么做这个

账号一多，真正的麻烦**不是记不住密码**，而是**认不出哪个是哪个**：

- **邮箱名长得全一样** —— `xk3n8d@gmail.com`、`xk3n8b@gmail.com`，谁是谁？
- **密码管理器帮不上** —— Bitwarden、KeePass 存的是纯文字，你还是得一个个点开看
- **截图堆成山** —— 相册里几十张账号截图，找一个翻半天
- **人脑认脸比认字快** —— 头像你一眼就认得出，邮箱你得逐个读

所以这个工具的答案很简单：**你把截图粘进来，它把头像和邮箱一起抠出来，之后你靠头像认号。**

---

## 核心能力：截图 → 头像 → 认得出来

这是项目的**全部重点**，其他功能都是配角。

<p align="center"><b>粘贴截图 &nbsp;→&nbsp; 自动抠出头像 + 邮箱 &nbsp;→&nbsp; 靠头像认号</b></p>

### 它怎么抠头像

程序会在头像位置**逐个采样像素**，然后判断属于哪种情况：

| 情况 | 判定依据 | 处理方式 |
|---|---|---|
| **真实照片头像** | 颜色杂乱（>10 种色簇，主色占比 <38%） | **直接裁剪原图**存为头像图片 |
| **首字母色块** | 颜色单一 | 还原成**同色**的字母头像 |

**关键点：首字母头像的颜色是从截图里读出来的真实颜色**，不是随机生成的。

识别出来的头像还能手动改：点一下就能换图，或者改字母和颜色。

### 截图 OCR 导入

- `Ctrl V` 直接粘贴，不用先存文件
- **全程本地识别**（浏览器内 WASM 跑 tesseract），截图不上传任何服务器
- 自动识别邮箱格式，把邮箱和昵称拆开
- 自动查重，标出「已存在」和「本批重复」
- 识别结果逐条可勾选、可修改，确认后再导入

> 不想走截图？主界面右上角**「添加账号」**随时手动录入单个账号 —— 见下面的「其他功能 → 手动添加」。

## 其他功能

### ➕ 手动添加

截图不是唯一入口。主界面右上角两个按钮并排：

<p align="center">
  <code>[ 截图导入 ]</code> &nbsp;&nbsp; <code>[ + 添加账号 ]</code>
</p>

点「添加账号」直接开一个空白卡片，手动填：

| 字段 | 说明 |
|---|---|
| **头像** | 上传图片，或者用首字母 + 挑颜色 |
| **名称 / 邮箱** | 手动输入 |
| **板块** | 选一个，或新建 |
| **标签** | 从标签库里选 |
| **备注 / 注册时间 / 密码 / 2FA** | 可选 |
| **快捷复制项** | 想加几条加几条 |

还有一处入口：**当某个板块是空的**（或搜索无结果）时，空状态里会直接给一个「添加账号」按钮，不用先切回主界面。

**什么时候用手动添加**：只有一两个号要补、截图里识别漏了某个号、或者要录的号根本不是从截图来的（比如朋友给的）。

### 🔐 本地加密

- 可选主密码，PBKDF2-SHA256（250,000 次迭代）派生密钥
- AES-256-GCM 加密整个库，盐值随机、每次加密独立 IV
- 数据存浏览器 IndexedDB，**无服务器、无数据库、无上报**

### 📁 板块分组

按邮箱类型分开管理，各板块有自己的颜色，侧栏一眼可辨（QQ / Google / Outlook / 其他 / 自建）。

板块可重命名、改色、删除；删除时能把里面的账号迁移到另一个板块。

### 🗂️ 标签系统

不只是字符串，是一个**可管理的标签库**：

- 独立标签库页面 —— 新建、重命名、改色、删除
- **删除有提示** —— 「该标签正被 12 个账号使用，删除后将从这些账号移除」
- **一键清理** —— 清掉所有没被使用的空标签
- 搜索覆盖标签名
- 卡片上最多显示 2 个，多了折成 `+3`

实用例子：`长期号`、`已验证`、`学生会员`、`GPT Plus`、`备用`、`即将到期`

### 📋 每个账号都有独立的内部空间

一个账号不只是「邮箱 + 密码」，它能装：

- **备注** —— 自由文本
- **注册时间** —— 支持 `2021`、`2021年`、`5年老号`，自动换算账号年龄
- **密码 / 2FA 密钥**
- **快捷复制项（无限条）** —— 每条有自己的名字、内容、图标、颜色、备注

快捷复制项才是真正好用的地方：

| 字段 | 说明 |
|---|---|
| 标签 | 如「登录口令」「备用邮箱」「API Token」 |
| 内容 | 要复制的文本 |
| **图标** | **自动识别** —— 填「验证码」给数字图标，填「手机」给手机图标，填 `api_key` 给代码图标 |
| **颜色** | 跟随图标自动配色 |
| **敏感保护** | 勾选后在卡片上遮盖，需点眼睛才显示 |
| 备忘说明 | 如「适用场景或过期时间」 |

也就是说，一个账号底下可以挂着：登录密码、PIN 码、备用邮箱、恢复码、订单号 —— **每项都能单独一键复制，敏感项自动遮盖**。

### 🖱️ 交互细节

- **卡片悬停快速复制** —— 不用点进详情
- **拖拽排序** —— 按自己的习惯排（dnd-kit）
- **邮箱脱敏** —— 一键隐藏，防旁人窥屏
- **搜索全字段** —— 名字、邮箱、注册时间、标签、备注一起搜
- **JSON 导入导出** —— 方便备份和换设备

## 和其他账号管理器的区别

| | 本工具 | 普通密码管理器 |
|---|---|---|
| 录入方式 | **粘贴截图，自动识别** | 手动逐条输入 |
| 认号方式 | **靠头像图片** | 靠文字搜索 |
| 账号内部 | **可挂多条快捷复制项** | 通常只有账号/密码/网址 |
| 敏感字段 | **逐项标记遮盖** | 整体加密 |
| 标签 | **独立标签库可管理** | 多为简单分组 |
| 存储 | 浏览器本地 | 通常有云同步 |
| 定位 | 多账号快速辨认 | 全量凭据保管 |

> 它**不是** Bitwarden / KeePass 的替代品。它是一个「谷歌号太多、认不过来」场景下的专用工具。

## 快速开始

需要 **Node.js 18+**。

```bash
git clone https://github.com/waw666waw666/account-vault.git
cd account-vault
npm install

# 准备 OCR 识别组件（截图导入功能需要，约 8.8MB，仅首次）
npm run setup:ocr

npm run dev
```

打开 http://127.0.0.1:5188/

### Windows 一键启动

仓库自带 `run.bat`，双击即可。它会自动检查 Node.js、安装依赖并启动服务。

停止服务：双击 `stop.bat`。

## 怎么用

**截图批量导入（推荐，一次录一批）**

1. 打开 http://127.0.0.1:5188/
2. 把账号列表**截图到剪贴板**（系统截图工具即可），或准备好图片文件
3. 页面里按 `Ctrl V` 粘贴
4. 等几秒 —— 本地 OCR 完成，每个账号的头像、昵称、邮箱都会列出来
5. 逐条确认（可改头像、改名字、取消勾选），点导入
6. 完成。之后靠头像认号，点一下复制邮箱或密码

> 截图来源可以是谷歌账号切换列表、邮箱客户端列表、任何「头像 + 邮箱」并排的界面。

**手动添加（单个补充）**

1. 主界面右上角点**「添加账号」**
2. 填名称、邮箱，选头像（上传图片 或 首字母 + 挑颜色）
3. 选板块和标签，需要的话补备注、注册时间、快捷复制项
4. 保存

> 截图识别漏了某个号、或者要录的号不是从截图来的，用这条。

## 关于 OCR 组件

`public/ocr/` 下的文件约 8.8MB，**不纳入 Git 仓库**（避免仓库臃肿），需要运行一次：

```bash
npm run setup:ocr
```

该脚本会：

1. 从 `node_modules` **复制** `worker.min.js` 和 `tesseract-core-simd-lstm.wasm.js`（版本与依赖严格一致，无需联网）
2. **下载** `eng.traineddata` 英文语言包（约 4MB，需联网一次）

若网络受限，可手动下载 [eng.traineddata](https://github.com/tesseract-ocr/tessdata_fast/raw/main/eng.traineddata) 放到 `public/ocr/lang/` 目录。

> 未准备 OCR 组件时，除截图导入外的所有功能均可正常使用。

## 数据与隐私

**数据存放在浏览器的 IndexedDB 中，与项目目录无关。**

这意味着：

- 清除浏览器数据、更换浏览器或使用无痕模式，**数据会丢失**
- 建议定期通过「设置与备份」导出 JSON
- 项目不含任何埋点、统计或上报逻辑

### 加密说明

开启主密码后，整个数据仓库会以 AES-256-GCM 加密后存储：

- 密钥由 PBKDF2-SHA256 派生，迭代 250,000 次
- 盐值随机生成，每次加密使用独立 IV
- **主密码一旦遗忘无法恢复**，请务必妥善保存

## 已知限制

- **OCR 目前仅支持英文识别**（`eng.traineddata`）。中文账号名会识别失败，需要额外语言包
- **头像色块扫描目前只在「单账号截图」时启用**。一张图里多个账号时走原有采样逻辑 —— 多账号的色块与文字行配对依赖 OCR 的行分割质量，尚不稳定
- **Windows 启动脚本为主**。`run.bat` / `stop.bat` 仅适用于 Windows，其他平台请用 `npm run dev`
- **无浏览器扩展形态**，需本地运行开发服务器
- 单用户、单机设计，不含多设备同步
